# Hermes Agent — Connector Catalog Inventory

Reference inventory of messaging-gateway platform adapters and third-party service
connectors in the Hermes Agent repo, for cataloging purposes only (no code reproduced).

Three sub-sources combined into one table:
1. Built-in gateway adapters — `gateway/platforms/*.py` (tier = `builtin`)
2. Plugin-based platform adapters — `plugins/platforms/*/adapter.py` (tier = `bundled-plugin`)
3. Nous Portal hosted connector catalog — one summary row (remote, non-local, not enumerable)

Built-in `gateway/platforms/` files that are shared infrastructure rather than distinct
platform adapters (skipped — no row): `__init__.py`, `_http_client_limits.py`, `_shared.py`,
`access_policy_mixin.py`, `ADDING_A_PLATFORM.md`, `api_server_memory_sessions.py`,
`api_server_openai_routes.py`, `api_server_room_dispatch.py`, `api_server_room_grants.py`,
`api_server_run_idempotency.py`, `api_server_runs.py`, `api_server_turn_boundary.py`,
`base.py`, `base_exec_approval.py`, `event.py`, `helpers.py`, `media_cache.py`,
`shared_ingress.py`, `signal_format.py`, `signal_rate_limit.py`, `tcp_site.py`,
`webhook_coalesce.py`, `webhook_filters.py`, `whatsapp_common.py`, `yuanbao_media.py`,
`yuanbao_proto.py`, `yuanbao_sticker.py` — these are siblings/helpers imported by the
adapter files, confirmed by grepping for `class .*Adapter(...BasePlatformAdapter)` across
the directory (9 matches, listed below, one of which — `qqbot/adapter.py` — lives in a
`qqbot/` subdirectory alongside its own helper siblings).

All Hermes-authored code in this repo is MIT-licensed (root `LICENSE`, Nous Research); no
per-file license markers deviate from this.
